This method performs computation of molecular energy. Method is based on the minimization of the energy
 across wave functions which can be represented as a sum of exactly k determinants.
As an input method requires computation of molecular integrals- namely, overlap matrix, kinetic energy matrix,nuclear attraction matrix and ERI tensor.
Energy of nuclear repulsion also should be pre-computed.
This data must be obtained using other software- for example, PyQint or PySCF.

In the usage examples #1 and #2 molecular integrals are calculated with PyQInt (https://github.com/ifilot/pyqint).
Usage examples #3 and #4 allow to reproduce results presented in the paper. Input data required for the computations is stored in the folders "oxygen atom" and "water molecule".


#Usage example 1
#import packages
import k_det
from pyqint import PyQInt, Molecule
#initialize molecule and basis set using PyQint
mol = Molecule()
integrator = PyQInt()
mol.add_atom('C', 0.0, 0.0, 0.0)
#6-31G basis set
cgfs, nuclei = mol.build_basis('p631')
#calculate integrals using PyQint
S, T, V, eri = integrator.build_integrals_openmp(cgfs, nuclei)
#calculate energy of nuclear repulsion
E_nuc_rep=k_det.calculate_nuclear_repulsion(nuclei)
#input molecular parameters
#number of electrons
n_electrons=6
#spin multiplicity
multiplicity=3
#random seed
rseed=42
#number of determinants
k=2
#run energy optimisation procedure using Python script for K-determinant optimisation
E,psi,data=k_det.optimize_molecular_energy(n_electrons,multiplicity,k,S,T,V,eri,E_nuc_rep,rseed)
